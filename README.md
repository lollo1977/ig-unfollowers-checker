# 🔍 Instagram Unfollowers Checker

Un semplice strumento web per scoprire quali account segui su Instagram che non ricambiano il follow, confrontando direttamente i dati esportati dal tuo account.

### 🔒 Privacy al 100%
- **Nessuna password richiesta:** Non rischi il ban o il furto del profilo associando app terze non autorizzate.
- **Elaborazione locale:** I tuoi file JSON vengono analizzati esclusivamente all'interno del tuo browser. Nessun dato viene caricato, salvato o inviato a server esterni.

---

### 📦 Come ottenere i file da Instagram

1. Apri Instagram e vai su **Impostazioni** > **Centro gestione account**.
2. Seleziona **Le tue informazioni e autorizzazioni** > **Scarica le tue informazioni**.
3. Scegli **Scarica o trasferisci informazioni** > Seleziona il tuo profilo.
4. Clicca su **Alcune informazioni** e spunta solo **Follower e persone che segui**.
5. Seleziona **Scarica sul dispositivo**:
   - **Intervallo di date:** *Sempre*
   - **Formato:** Seleziona obbligatoriamente **JSON** (non HTML)
6. Quando l'archivio ZIP è pronto, scaricalo ed estrailo. Troverai i file nella cartella `followers_and_following/`.

---

### 🚀 Come usarlo

1. Apri il tool online.
2. Carica il file `followers_1.json`.
3. Carica il file `following.json`.
4. Clicca su **Confronta Liste** per visualizzare i risultati con il link diretto ai profili.
5. Per accedere al programma https://lollo1977.github.io/ig-unfollowers-checker/
